TEXTACK

typing = damage  //  siege the fortress — Linux terminal game, 100% open source

★ GitHub How to play
▲ Typing = DamageType a Linux command + Enter = shot. Faster = harder hits.
✦ Survivor Upgrades14 upgrades in 4 classes: ATTACK / DEFENSE / SPEED / BASE. Base Cannon fires automatically.
▼ Enemy WavesSCOUT → RAIDER → GOLEM → OVERLORD. BOSS every 5 waves. Interval + burst scale up.
♥ LearnEvery word is a real Linux command. Play while memorizing `grep`, `chmod`, `ps aux`.
◆ AIKA + SoundOperator waifu reacts + SFX via paplay. Swap art in waifu.txt, sounds in sfx/.

Run it

git clone https://github.com/rewsaqy/Textack.git
cd Textack
python3 main.py
# or install the command: pip install -e . && textack

Needs only stock Python 3 (curses). Native Linux, 60fps, no extra installs. Windows: pip install -e . (windows-curses auto-installs).
